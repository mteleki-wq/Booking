Create the venue

In Supabase → SQL Editor → New query. This makes the restaurant and its own capacity settings, so their seats stay separate from every other client's.

02

Create their login

In Supabase → Authentication → Users → Add user. Use the manager's email, set a password, and tick the option to confirm it automatically.

Then run this to attach that login to their restaurant. From here, row level security means they can only ever see their own bookings and guests.
